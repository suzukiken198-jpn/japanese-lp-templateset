# テンプレート集の案内LP

収録テンプレートとは別の、パッケージを紹介するWebページです。ソースはこの `site/` フォルダに置きます。

- 編集: `index.html`（文章・構成）、`styles.css`（見た目）。
- 収録カード・件数: ルートの `templates.json` からビルド時に生成します。
- ビルド: リポジトリのルートで `npm run build:site`。
- ローカル確認: `npm run dev:site`。ブラウザで `http://localhost:4175/`。
- Vercel: リポジトリのルートを選択。`vercel.json` の設定で `site/dist` を公開します。
- note: 申込案内は現在準備中。受付開始時は `docs/SUBSCRIPTION.md` と案内LPの準備中表示・リンクを更新し、料金・販売条件の整合性を確認してください。

申し込み・決済・会員管理・追跡機能は含みません。フォームはありません。収録画像をデザインイメージとして再利用しています。
