# 業種別LPテンプレート・サブスクリプション計画

- 共通リポジトリ: https://github.com/suzukiken198-jpn/japanese-lp-templateset （公開）。
- 月額: 2,500円。税表示・課金日・返金等の販売条件は受付開始前に確定する。
- ライセンス: 独自商用ライセンス。MITではない。
- 契約中: 自社・顧客サイトの制作・改変・納品が可能。サイト数制限なし。
- 解約後: 契約中に制作済みのサイトは継続運用・保守可能。新しい商用サイトの制作には再契約が必要。
- 申込・決済: note。申込URLは後日追加。現在は受付準備中。
- 初期目標: 業種別で約10サイト。現在はライブ・イベントLPと代官山のライフスタイル・カフェLPの2サイト。
- 新作: ユーザーが現在制作中のサイトを順次追加。未完成・ソース未収録のサイトを収録済みに数えない。
- ジムLP: 公開URLの共有あり。編集可能なソースの確認・取り込みは未実施。
- 配布: サイトごとの編集用ソース・画像・ガイド、まとめZIP。フォーム等の未接続機能を明示する。
- 本リポジトリの作成では決済・会員管理・自動課金を実装しない。

公開リポジトリではソースは誰でも取得できるが、商用利用には別途有効な契約が必要。料金は無料ダウンロードの制限ではなく、商用利用権に対して設定する。素材単体・テンプレート集の再販売はサイト制作許諾に含まれない。

今後決めること: 商品名、販売条件の詳細、販売開始日、新作の追加頻度、サポートの有無・範囲。毎月の追加本数や10サイト収録済みであることを、未達の段階で約束しない。

独自ライセンス・販売条件は、販売開始前に専門家による確認を推奨する。
