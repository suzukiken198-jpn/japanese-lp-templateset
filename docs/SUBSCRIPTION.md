# 商用利用のお申し込み

**受付準備中です。noteの申込URLは後日ここに追加します。**

- 月額: 2,500円。税表示等の販売条件は受付開始前に明示します。
- 契約中: 自社サイト・顧客案件の制作、改変、納品が可能です。サイト数制限はありません。
- 解約後: 契約中に制作済みのサイトは運用・保守を継続できます。新しい商用サイトを制作する場合は再契約が必要です。
- 取得済みテンプレートであっても、新規商用制作時には有効な契約が必要です。
- 素材単体・テンプレート集の再販売は、このサイト制作許諾には含まれません。

正式な条件は [LICENSE](../LICENSE) を確認してください。GitHubからのダウンロードやForkだけでは、商用契約は成立しません。

## 運営者向け: noteを追加するとき

1. ここに正式なnote申込URLを掲載します。現時点では仮URLを載せません。
2. note側で価格の税表示、利用開始・終了、課金日、解約方法、返金等の販売条件、必要な販売者表示を整えます。
3. 契約者が同意するライセンスの版を記録し、申込・決済と利用期間を確認できる運用を決めます。
4. テストで申込案内と契約確認の流れを確認してから、README等の「準備中」を解除します。

このリポジトリには決済機能・会員管理・noteとの自動連携はありません。購入者情報や決済記録を公開Issueやリポジトリに保存しないでください。販売開始前に独自ライセンス・販売条件の専門家確認を推奨します。
