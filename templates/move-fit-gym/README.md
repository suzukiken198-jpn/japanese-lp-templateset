# MOVE FIT GYM

黒・白・ライムグリーンを使ったフィットネスジムのLPです。写真、文章、ボタンを別々に編集できます。

## はじめ方

Node.js 22で、このフォルダを開いて `npm ci`、`npm run dev` を実行します。
確認URLは http://localhost:4177/ です。`npm run build` で `dist/` に公開用ファイルを作成します。
`npm test` で画像・リンク・デモフォームの静的チェックを実行できます。

## 内容

プログラム紹介、トレーナー、施設、料金プラン、会員の声、アクセス、FAQ、体験予約フォーム。
予約は入力確認までのデモです。実際の送信・予約確定・決済は行いません。
店舗・人物・料金・体験談はデザイン見本です。
