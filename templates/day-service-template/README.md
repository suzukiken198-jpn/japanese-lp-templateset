# やすらぎデイサービス — デイサービスLPテンプレート

白・オレンジ・緑を使った、明るくやさしい雰囲気の通所介護向け1ページサイトです。写真と文字を分けているため、事業所名や説明文、料金、リンクを変更できます。

## できること

- サービス・理念・スタッフの詳細を開く
- 利用者の声の切り替え、よくある質問の開閉・追加表示
- スマートフォンのメニュー操作
- サービスや料金の詳細から相談フォームへ進む
- 相談フォームの入力チェック、確認、修正、デモの終了

相談フォームは**入力・確認だけのデモ**です。送信、保存、予約確定、決済はしません。実際の個人情報や介護・健康情報は入力しないでください。

事業所名・写真・スタッフ・利用者の声・実績・料金・住所・電話番号は架空の表示例です。実際の運営に合った正確な情報へ変更してください。

## 確認・編集する

```sh
npm ci
npm run dev -- --port 4182
```

ブラウザーで `http://localhost:4182/` を開きます。`index.html` を直接開く方法では正しく表示されません。

```sh
npm run build
npm test
npm run preview -- --port 4182
```

公開用ファイルは `dist/client/` です。Vercelにはこのフォルダを公開する設定を同梱しています。
