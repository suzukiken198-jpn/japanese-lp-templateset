# 編集・利用ガイド

## 主な変更場所

| 変更したいもの | ファイル |
| --- | --- |
| 事業所名・見出し・住所・電話番号・料金・メインの説明文 | `src/App.jsx` |
| サービス・利用者の声・流れ・FAQ・メニュー | `src/content.js` |
| 相談フォーム・確認画面 | `src/Dialogs.jsx` |
| 色・文字サイズ・余白・スマホ表示 | `src/home-care.css` |
| 写真・ロゴ・地図 | `public/assets/` |
| ブラウザーのタイトル・検索用説明 | `index.html` |

写真を同じファイル名で差し替えると、新しい写真を表示できます。別名にした場合は、対応するコードも変更してください。写真の上の見出しや本文、料金、ボタンはHTMLの文字なので編集できます。

## 相談・お問い合わせを使うには

現在は入力・確認だけです。送信・保存・予約確定・空き状況の確認・決済には対応していません。画面にある「24時間相談対応」も表示例であり、実際の受付を意味しません。

外部の予約・問い合わせサービスのURLにボタンをつなぐか、ご自身で送信機能を開発して接続してください。送信機能を追加する場合は、個人情報の扱い、同意文、迷惑送信対策、送信結果とエラーの表示を用意します。特に介護・健康に関する情報を扱う場合は、収集する情報と運用の適切さを確認してください。

## 公開前に変更・確認すること

- 事業所名、運営者情報、対応地域、営業時間、住所、実在の連絡先。
- 地図画像とGoogleマップの行き先。現在は架空の地図で、クリックすると設定案内が開きます。
- 料金、自己負担の説明、実績年数、対応時間、資格の表記。掲載内容を実際のサービスと照合する。
- 写真の利用許可・肖像権、本人の同意を得た紹介文・利用者の声。現在はすべて架空のイメージ。
- お知らせの日時と内容。架空のイベント案内をそのまま公開しない。
- 電話ボタン。現在は架空の電話番号への発信を防ぐため、説明を開きます。
- プライバシーポリシーを実際の運営に合わせる。
- フォームの接続と動作確認を終えてから、デモ用の注意書きを見直す。
- スマホ、キーボード操作、サービス詳細、フォームの修正、FAQの開閉を確認する。
