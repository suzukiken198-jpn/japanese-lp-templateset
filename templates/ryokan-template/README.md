# 旅館LPテンプレート「月の湯」

元デザイン `ryokan.png` の露天風呂・和紙・金色・明朝体の雰囲気を生かした、写真とHTML文字を別々に編集できる旅館向けLPです。

## できること

メニューからの移動、客室・料理・温泉・館内の詳細表示、季節でのプラン絞り込み、予約希望の入力・確認・修正、アクセス・観光案内を操作できます。

予約フォームはデモです。送信・保存・空室照会・予約確定・決済は行いません。旅館名・写真・料金・設備・温泉情報・地図は架空のサンプルです。実際に使う際は、ご自身の施設の情報に変更してください。

## 起動と編集

Node.js 22.12以上の22系で、`npm ci`、`npm run dev` の順に実行します。
`npm run build` で公開用ファイルが `dist/client/` にできます。`index.html` を直接開かず、開発サーバーで確認してください。
