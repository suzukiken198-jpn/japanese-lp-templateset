# 編集ガイド

## 文章・料金を変える

`src/App.jsx` の冒頭に、宿の紹介 `features`、宿泊プラン `plans`、周辺観光 `sights` をまとめています。名前・説明・価格・期間を変更できます。

旅館名はロゴ画像にも含まれています。変更する際は `public/assets/logo.png`、画像の説明文、ページのタイトルもあわせて変更してください。

`src/ryokan.css` では文字の大きさ、余白、色、スマートフォン表示を編集できます。見出しやボタンの文字は画像ではありません。

## 写真を変える

`public/assets/` 内の画像を差し替えます。対応表は `ASSETS.md` にあります。元画像は参考デザインであり、各写真はその雰囲気に合わせて生成した別素材です。

## 本当の予約を受け付けるには

現在のフォームは入力・確認だけです。宿泊希望は外部に送信されず、ページを閉じると消えます。料金計算・空室確保・予約確定・メール通知・支払いはできません。

外部の予約サービスを使う場合は、`cta` が作るボタンと、各プランの選択ボタンを、ご契約の予約ページへのリンクに置き換えてください。予約サービスから渡された正式なURLを使用します。

独自に開発する場合は、空室管理、サーバー側の入力確認、料金計算、個人情報の安全な保存、メール通知、取消・変更処理などを別途実装してください。画面の確認だけで予約完了を表示しないでください。

## 地図と観光案内

地図・駅名・所要時間は架空です。実在する住所やGoogleマップ等の正式なURLに置き換えてください。今は誤った道案内をしないよう、サンプルの説明が開く仕組みです。

## 公開前に確認すること

- 写真の使用条件、旅館名、設備、源泉・泉質等の表示を確認する。
- 料金の条件、税・入湯税・追加料金・キャンセル条件を設定する。
- 予約先・連絡先・地図を接続し、スマートフォンとパソコンで動作を確認する。
- 架空のサンプルから実情報への置き換えが終わったら、デモの注記を適切な案内に変更する。
- コピー・納品時は `LICENSE` と第三者ライセンス表示を残す。

## Vercelで公開する場合

このフォルダを公開対象に設定し、ビルドを `npm run build`、出力先を `dist/client` にします。テンプレート集へ収録する場合の配置先は `templates/ryokan-template/` です。
