# ケーキ屋テンプレートの編集ガイド

## 文字や価格を変える

店名、見出し、住所は `src/App.jsx` を編集します。商品と価格は `src/content.js` の `products` を編集します。価格は円単位の数値です。カテゴリーを増やす場合は `categories` も更新してください。

ホールケーキのサイズと価格は `src/Dialogs.jsx` の `price` とサイズの選択欄にあります。現在は4号3,600円、5号4,500円、6号5,400円の表示例です。値を変更したら、確認画面の合計も確かめてください。

## 写真を変える

`public/assets/` の各画像を同名のPNGに差し替えます。横長のメイン写真、商品写真、職人の写真などは別々のファイルです。詳しい対応は `ASSETS.md` を参照してください。別形式にする場合は、`src/App.jsx` と `src/Dialogs.jsx` の画像拡張子も合わせて変更します。

写真に見える見出しやボタンはHTMLです。写真を変えても文字を自由に編集できます。ただし、ケーキのプレートの「Lumière」「Happy Birthday」や店の看板は写真に含まれます。

## 注文・予約を受け付けるには

今の注文画面は操作を体験するためのデモです。入力は画面を閉じると消え、サーバーや端末の保存領域には保存されません。

実際の運用では、オンラインショップや予約サービスのURLを設定するか、受注用の仕組みを別途開発してください。決済、在庫管理、メール通知、サーバー側の入力チェックは含まれていません。外部サービスへ切り替える場合は、ショップボタンや商品ボタンから正しいURLへ移動するようにします。

## 公開前のチェック

- 架空の店名・住所・アクセス・駐車場・年数を実際の情報に変更する。
- 商品名、価格、税の表示、写真、原材料、アレルギー情報を実際の商品に合わせる。
- お知らせの過去日付と内容を更新する。
- Googleマップ、SNS、お問い合わせは未接続。正しいリンクに置き換える。
- 営業日・受け取り可能日・予約期限を実際の運用に合わせる。
- 販売に必要な案内、個人情報の取り扱い、事業者情報を用意する。
- デモ表記は、実際の機能を接続して動作を確認してから変更する。
- スマートフォンで表示と操作を確認する。

## 公開設定

VercelのRoot Directoryは、このフォルダを指定します。将来パック内へ移す場合は `templates/cake-shop-template` を指定します。

| 項目 | 値 |
| --- | --- |
| Framework | Vite |
| Install Command | `npm ci` |
| Build Command | `npm run build` |
| Output Directory | `dist/client` |

テンプレート集への追加・公開設定の変更は、提供者が行います。このガイドは利用者側でのサイト編集を説明するもので、公式リポジトリの共同編集を募集するものではありません。
