# relie DAIKANYAMA — 利用ガイド

写真とHTMLの文字を分離したライフスタイル・カフェ向けLPです。

## 利用条件

月額2,500円の独自商用ライセンスです。契約中は自社・顧客サイトを制作・改変できます。契約中に制作したサイトは解約後も運用・保守できますが、新しい商用サイトを制作する場合は再契約が必要です。noteでの申込受付は準備中です。詳しくは [LICENSE](LICENSE) を確認してください。

## 起動・編集

Node.js 22.12以上の22系を用意し、このフォルダで実行します。

```sh
npm ci
npm run dev
```

| 変更箇所 | ファイル |
| --- | --- |
| 店名・本文・商品・ダイアログ・ナビ | `src/App.jsx` |
| 色・余白・文字・写真の切り出し位置 | `src/styles.css` |
| 写真 | `public/assets/relie-background.png` |
| 検索向けタイトル等 | `index.html` |

写真は1枚から各セクションの範囲をCSSで表示しています。別の写真を使用するときは背景位置・サイズも調整してください。

## 動作と未接続部分

商品・カフェ・読みものの詳細ダイアログ、モバイルメニュー、来店案内があります。住所・営業時間は「ご案内準備中」です。予約確定・決済を行うシステムではありません。実店舗の情報と予約リンク等を設定し、PC・スマホで確認してから商用公開してください。

## ビルドと公開

```sh
npm run build
npm run test:sites
```

VercelのRoot Directoryは `templates/daikanyama`、出力先は `dist/client` です。単独のリポジトリにコピーした場合はこのフォルダをルートにします。`dist/client` 全体とLICENSE・第三者表示を公開してください。

Sites向けの補助ファイルは保持しています。既存の公開先を変更する必要はありません。このテンプレート集への収録だけで、元サイトや元リポジトリが自動更新されることはありません。
