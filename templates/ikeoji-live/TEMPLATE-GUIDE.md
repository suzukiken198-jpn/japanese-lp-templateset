# 01 / ライブ・イベントLP — 利用ガイド

黒・濃紺・金を基調にしたイベント向けLPです。コンサート、小規模ライブ、トークイベントなどのページ制作の出発点として利用できます。

## 利用できる範囲

独自の商用ライセンスです。月額2,500円の有効契約中は、自社・顧客サイトの制作、文字・画像の変更、複数サイトへの利用ができます。契約中に制作済みのサイトは解約後も運用・保守できますが、新しい商用サイトの制作には再契約が必要です。素材単体・テンプレート集の再販売はこの許諾に含まれません。noteの申込先は準備中です。コピーや納品物には `LICENSE` と必要な第三者ライセンス表示を含めてください。サイトのフッターに制作者名を表示することを追加条件にはしていません。

## 最初の準備

1. ZIPを展開するか、GitHubからソースを取得します。
2. Node.js 22.12以上の22系を用意します。
3. フォルダ内で `npm ci` を実行します。
4. `npm run dev` でプレビューします。

## 自分のサイトへ変更する

| 変更したいもの | ファイル・場所 |
| --- | --- |
| ページ名・検索向け説明 | `index.html` の title・description |
| メイン見出し・イベント名・日時・場所 | `src/Landing.jsx` の hero / event-overview |
| 予約ボタンの行き先 | `src/Landing.jsx` の Cta コンポーネントの href |
| 本文・紹介・比較表・FAQ | `src/Landing.jsx` の各セクションと配列 |
| 色・余白・文字サイズ | `src/landing.css` |
| PC用メイン写真 | `public/assets/separated/hero.jpg` |
| スマホ用メイン写真 | `public/assets/separated/hero-mobile.jpg` |
| その他の写真 | `public/assets/separated/` の各JPEG |

写真を差し替える際は、同じファイル名と近い縦横比にすると調整しやすくなります。本文を編集した後は、PCとスマホの両方で文字が写真に重なりすぎていないか確認してください。

## フォームについて

このテンプレートには、入力チェック・内容確認・修正の画面を含みます。メール送信・予約確定・決済の機能は含みません。現状の入力内容は送信も保存もされません。

受付に使う際は、既存の予約サービスへのリンクやフォームサービスを設定してください。実際の送信処理を接続して確認するまでは、受付準備中の表示を残します。

日時・会場・出演者・料金・席の有無・キャンセル条件はサンプルまたは未確定の表示です。自分のサービスの内容に置き換えてから公開してください。

## 公開する

`npm run build` で `dist/` に公開用ファイルを出力します。HTML・画像・CSS・JavaScript・ライセンスを含む `dist` 全体をホスティングします。ローカルで確認する場合は `npm run preview` を使用します。HTMLファイルのダブルクリックではなく、HTTPサーバーで開いてください。

Vercelでは自分のリポジトリをインポートし、ビルドコマンドを `npm run build`、出力を `dist` に設定します。サンプル作者のVercelアカウントへの接続情報は配布物に含まれません。

## 納品・配布用ZIPを作る

`npm run package:template` を実行すると、`releases/` にバージョンと日時を含むZIPとSHA-256チェックサムを作ります。既存ZIPを上書きせず、ソース、公開用ファイル、写真、ガイド、ライセンスを同梱します。
