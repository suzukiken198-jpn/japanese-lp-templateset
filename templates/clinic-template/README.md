# そら内科クリニック — クリニックLPテンプレート

白・水色・青緑を使った、明るいクリニック向けの1ページサイトです。写真と文字を分けて作っているため、院名や説明文、ボタンの行き先を変更できます。

## できること

- 診療案内、医師紹介、院内設備の詳細を開く
- 院内写真の切り替え、FAQの開閉
- スマートフォンのメニュー操作
- 予約フォームの入力、入力チェック、確認、修正

予約フォームは**入力・確認だけのデモ**です。送信、保存、予約確定、空き枠の確認、決済はしません。実際の個人情報・症状は入力しないでください。

院名、医師名、住所、診療時間、写真、地図は架空の表示例です。実際に使う場合は、正しい情報と運営者の確認済みの案内文に変更してください。

## 確認・編集する

```sh
npm ci
npm run dev -- --port 4181
```

ブラウザーで `http://localhost:4181/` を開いてください。`index.html` を直接開く方法では正しく表示されません。

```sh
npm run build
npm test
npm run preview -- --port 4181
```

公開用ファイルは `dist/client/` に出力します。詳しい編集方法は [TEMPLATE-GUIDE.md](./TEMPLATE-GUIDE.md) をご覧ください。

## 写真と利用条件

個別の画像16点は `public/assets/` にまとめています。生成した写真・ロゴ・架空の地図であり、実在のクリニックや医師を示すものではありません。生成記録は [ASSETS.md](./ASSETS.md) にあります。
