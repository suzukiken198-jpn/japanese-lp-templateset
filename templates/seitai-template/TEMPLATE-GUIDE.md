# 編集ガイド

## 文章・料金・院情報

`src/main.jsx` にナビゲーション、施術メニュー、FAQ、お客様の声、院長名、住所、営業時間があります。実際の整体院情報へ変更してご利用ください。

## 写真

`public/assets/` の `hero.png`、`consultation.png`、`treatment.png` を同じファイル名の写真へ差し替えると反映されます。

## 予約

現在の予約導線は入力・確認のみのデモです。実際の予約サービスへ接続する場合は、送信先、空き枠管理、通知、個人情報の取り扱いを別途用意してください。

## 公開

`npm run build` でビルドできます。公開用フォルダは `dist` です。公開前にサンプル情報、写真の利用権、予約先、プライバシーポリシーを確認してください。
